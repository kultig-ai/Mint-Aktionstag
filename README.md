# MINT-Aktionstag 🚀

Ein Mitmach-Projekt der **RheinEnergie** für Schüler*innen.

## Worum geht es?

Beim MINT-Aktionstag entwickeln wir gemeinsam und live eine Webseite – und zwar **eure** Webseite!

Ihr erzählt kreativ, was für eine Webseite ihr euch wünscht:

- 🎨 Wie soll sie aussehen?
- 🧩 Was soll man darauf machen können?
- 💡 Welche verrückten Ideen habt ihr?

Aus euren Ideen entsteht dann ein Prompt, und eine KI (Claude) entwickelt die Webseite direkt vor euren Augen.

## Ablauf

1. **Ideen sammeln** – Alle dürfen mitreden: Was soll die Webseite können?
2. **Prompt schreiben** – Wir fassen eure Wünsche in einen Auftrag für die KI zusammen.
3. **Zuschauen & Staunen** – Die KI baut die Webseite live.
4. **Ausprobieren** – Wir testen das Ergebnis gemeinsam und verbessern es.

## Projektstruktur

```
Mint-Aktionstag/
├── README.md   ← Diese Datei
└── ...         ← Hier entsteht eure Webseite!
```
